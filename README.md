Luxury Automotive — Interactive Portfolio

A modern and cinematic automotive website built with HTML, Tailwind CSS, JavaScript, and GSAP.

The project focuses on creating a premium digital experience through bold typography, immersive automotive imagery, smooth transitions, and scroll-driven animations.

✨ Features

- Fully responsive design for desktop, tablet, and mobile
- Cinematic automotive-inspired visual design
- Smooth scroll-based animations
- GSAP-powered transitions and interactions
- ScrollTrigger pinned sections
- Animated hero section with parallax effects
- Image reveal and overlapping transitions
- Interactive service showcase
- Responsive navigation
- Social media and contact sections
- Minimal and luxury-focused UI
- Optimized layout for different screen sizes

🛠️ Built With

- HTML5
- Tailwind CSS
- JavaScript
- GSAP
- ScrollTrigger
- CSS3

🎬 Animation

A major focus of this project is the use of GSAP and ScrollTrigger to create an immersive scrolling experience.

Animations include:

- Hero image parallax
- Text reveal animations
- Pinned sections
- Vertical image transitions
- Service slide animations
- Image overlap effects
- Scroll-controlled storytelling
- Smooth entrance and exit transitions


🎯 Purpose

This project was created as a front-end portfolio project to explore modern web design, responsive layouts, advanced JavaScript interactions, and cinematic scroll-based animation.

The goal was to create an experience that feels less like a traditional website and more like an interactive automotive presentation.
